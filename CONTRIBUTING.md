# Contribution policy

Shoalrun is maintainer-led. We are not accepting unsolicited pull requests at this time. Please do not start work expecting it to be reviewed or merged. For an invited contribution, the maintainer will confirm its scope before work begins.

## Report a problem

Bug reports and reports of documentation errors are welcome in [issues](https://github.com/shoalrun/shoalrun/issues). There is no guaranteed response time or commitment to implement a fix.

Search existing issues first. Include your Shoalrun version, Node.js version, operating system, reproduction steps, and expected versus actual behavior. For rendering problems, include your browser version and whether HTML, Markdown, or both are affected.

Share the smallest example that reproduces the problem. Remove credentials, private API descriptions, customer data, and personal paths from examples and logs. Report suspected vulnerabilities through [SECURITY.md](SECURITY.md), not a public issue.

You do not need access to the separate website repository to report a documentation problem. Include the public page URL or bundled document ID.

## Work on your own fork

The [development instructions](README.md#develop-the-framework) describe how to build and test a checkout. They are available for people maintaining their own forks as well as for project maintenance. Follow the [Apache-2.0 license](LICENSE) and retain applicable third-party notices when modifying or distributing the code.
