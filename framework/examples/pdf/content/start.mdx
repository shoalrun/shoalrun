Create a workspace before running daily operations. Keep its configuration in your project so another operator can reproduce the setup.

## Configure the workspace

Save the following example configuration:

```yaml
workspace:
  name: training
  retentionDays: 30
```

## Verify the result

Confirm that the workspace name is `training` and that retention is 30 days. Continue with [daily operations](doc:guide.operations).
