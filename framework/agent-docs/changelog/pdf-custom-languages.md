**Published: 2026-11-05.**

**Version: 0.1.0-beta.1.**

Upgrade to CLI `0.1.0-beta.1` and rebuild to use these features.

## [Print a page](https://www.shoalrun.com/publish/pdf.md)

Add an optional, configurable **Print PDF** button with branded styling. Static sites use the reader's browser.

## [Export a styled manual](https://www.shoalrun.com/publish/pdf.md)

Export a page or full publication with custom fonts, covers, contents, and page layouts. CLI exports and optional Node downloads require installed Chrome or Chromium; static printing doesn't. The new `shoalrun-pdf` skill guides agents through print design.

## [Highlight your own code language](https://www.shoalrun.com/author/components/code-blocks.md)

Register a local TextMate JSON grammar containing syntax-coloring rules, then use its language ID or aliases in code fences.
