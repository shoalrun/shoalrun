# Safer exports and easier discovery for AI assistants

**Published: 2026-10-26.**

**Version: 0.1.0-alpha.7 and 0.1.0-alpha.8.**

Today's two private-alpha releases make documentation safer to reuse and easier for AI assistants to find. **Alpha.7 keeps exported images and links attached to the right document. Alpha.8 lets assistants choose a topic before reading a directory of every page.**

Both versions are published in the private package registry. Upgrade to CLI `0.1.0-alpha.8` and rebuild your site to receive both sets of changes.

## Find documentation by topic

Previously, the starting directory listed every published page. Each new page made that directory longer, so an assistant had to read more text before choosing what to open.

Now, larger sites link to smaller topic directories. An assistant looking for deployment instructions can choose **Publishing**, then open the relevant page. Topic names come from your project's categories, or page types when categories are absent. If a directory grows too large, Shoalrun divides it again. Small sites can still list their pages directly.

Every published page remains reachable, including pages outside the website's navigation. On Shoalrun's own site, the starting directory shrank from roughly 6,000 tokens to 400. Tokens are the pieces of text an AI model reads. Larger sites may require more directory steps, but each step stays small.

Assistants still start at `/llms.min.txt`. If you maintain a script that reads this file, update it to follow topic-directory links instead of expecting every page in the first response. The complete catalog remains at `/llms.txt`. Independently readable sections retain their sizes and links to the full page.

## Keep exported images and links with their pages

Two documents can share a website route while needing different images or links in an exported bundle. Alpha.7 keeps each document's own assets and link destinations in exported HTML and Markdown. This also covers cards, related reading, cookbook choices, deprecation notices, and changelog notices.

The [help-drawer example](https://www.shoalrun.com/publish/content-export.md) now moves keyboard focus into opened content and follows links to specific headings. Closing the drawer with Escape returns focus to its launcher.

## Check your output destination

Use a real directory as the build or export destination. A destination that is itself a symbolic link is now rejected; symbolic links in its parent directories remain supported.

Shoalrun also rejects paths that escape the output directory, empty path segments, unsafe export mount paths, and duplicate output aliases before writing. Different paths to the same parent directory share one output lock, preventing competing builds from writing there at the same time. The export manifest remains at schema version 1.

## Technical details and validation

Compact directories have a 2,000-token limit, measured with `cl100k_base`. This limits each response, not the total reading needed for a question. A title or summary that cannot fit in one entry still needs shortening. Tests cover 160 to 1,600 pages, large topics, hundreds of topics, and reachability of every published page and declared standalone section.

The MCP server and client packages move to version `2.3.0`. Zod moves to `4.6.6`, and KaTeX to `0.18.2`. MCP tool arguments are limited to 1,024 elements before schema validation. HTTP requests retain the 64 KiB body limit and a separate server instance for each request.

These updates address advisories for [MCP connection isolation](https://github.com/advisories/GHSA-jm63-cq47-j5jp), [MCP input validation](https://github.com/advisories/GHSA-46jr-4wx8-v453), [MCP bearer-token audience checks](https://github.com/advisories/GHSA-rvq5-wwqv-78pq), [Zod collection validation](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5), and [KaTeX inherited settings](https://github.com/advisories/GHSA-238p-pmpm-9mq7).

Alpha.7 validation passed 723 framework tests, all five packaged skill checks, and clean installations of the minimal and API-documentation starters. Its dependency audit reported no vulnerabilities at validation time. Package checks also inspect the file inventory and exercise the installed help drawer in a browser. Test runs limit concurrency to four files, rebuild tests wait for complete server events, and skill validation reports missing Python prerequisites with setup instructions.

This remains an alpha release. Publishing the CLI does not automatically upgrade or deploy an existing site. See [Agent-friendly documentation](https://www.shoalrun.com/publish/agent-friendliness.md) for the reading workflow and [portable content exports](https://www.shoalrun.com/publish/content-export.md) for reuse in another application.
