**Published: 2026-10-30.**

**Version: 0.1.0-alpha.14.**

Alpha.14 fixes selected-text contrast and paragraph widths in expanded layouts. Upgrade to CLI `0.1.0-alpha.14` and rebuild your site to receive both fixes. No configuration changes are needed.

## Read selected text

Text selection now pairs the highlight background with its contrasting foreground. Previously, selection used the heading ink color, which could become difficult to read in dark mode. The selection pair passes the contrast checks across all six built-in palettes in light and dark modes.

## Fill expanded layouts

Paragraphs and ordinary lists now fill their available containers in `wide`, `landing`, and `splash` layouts, including nested sections. Previously, these elements kept a 68-character reading limit even when the surrounding layout was wider.

Standard documentation pages retain that reading limit. Splash sections remain centered within the landing width, and hero text and other components keep their own limits. See [page layouts](https://www.shoalrun.com/styling/layouts.md).

## HTML, Markdown, and agents

These fixes affect browser colors and line widths. Markdown content, page identities, and agent retrieval contracts stay the same. Selecting text and resizing the page need no JavaScript.
