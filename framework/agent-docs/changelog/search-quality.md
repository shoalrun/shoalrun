## [Faster, more accurate search](https://www.shoalrun.com/author/search.md)

Search now indexes complete pages at build time, with stronger matches for titles, headings, API symbols, and CLI flags. It handles common typos and gives current documentation priority over changelog entries for everyday questions.

Static sites get these improvements without a search server. Hosted search retains semantic matching and adds optional, configurable model assistance to help select the best result.
