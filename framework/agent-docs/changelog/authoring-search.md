Prepared for the next prototype release:

- **Agent authoring:** Skills, templates, project directives, source context, and checked edit plans help your existing agent draft and update documentation.
- **Writing guidance:** Design templates and project writing guides, with a complete example to adapt.
- **Search:** Semantic ranking, exact-key assistance, and clearer snippets. Word matching provides fallback results when embeddings fail or exceed the three-second deadline.
- **Ask:** Follow-ups keep their topic, and explicit multi-part questions get evidence for each part. Citation and claim checks remain; multi-topic answers are experimental.
