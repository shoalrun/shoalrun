**Published: 2026-10-27.**

**Version: 0.1.0-alpha.11.**

The October 27 releases improve reading and navigation, add a complete feature-showcase starter, and give agents page types and sizes before they fetch content. The documentation site also gets a refreshed logo and smaller configuration references.

Upgrade to CLI `0.1.0-alpha.11` and rebuild your site to receive the framework changes from alpha.9 and alpha.10. Existing navigation configuration continues to work. The logo and reorganized reference are updates to this documentation site.

## Install from public npm

Alpha.11 moves the CLI to the public npm registry. Installation no longer needs an invitation, GitHub package access, or a package token. Follow [Getting started](https://www.shoalrun.com/start.md) for an exact-version install. If you used the earlier private alpha, remove or replace the old `@shoalrun` registry override and update the manifest and lockfile together.

The package README now leads with the showcase. Starter instructions explain how to replace the fictional API and its connected operation bindings. Alpha.11 keeps the site configuration and output contracts from alpha.10.

## Explore a complete starter

Alpha.10 adds a fictional Cedar Parcel handbook with 18 pages. It includes component examples, code walkthroughs, Mermaid and D2 diagrams, reader views, a landing page, a local-workflow cookbook, and generated API references. **Explore the starter** is the first page in its navigation and maps the working examples.

```sh
shoalrun init my-handbook --starter showcase
cd my-handbook
shoalrun build docs.config.yaml site-dist
shoalrun serve site-dist
```

The starter builds without provider credentials. Hosted chat, analytics, and remote services need your own configuration. The `minimal` and `api-docs` starters remain available. See [example projects](https://www.shoalrun.com/config/examples.md).

## Read controls and prose comfortably

Alpha.10 increases small reader, code, and API control labels. Ordinary lists use the same reading measure as paragraphs, while tables, code, and file trees retain their available width. Mobile header tools share a row when space permits, and search results fit within the header width.

## Choose a page before fetching it

Compact discovery and navigation indexes now include each page's content type and full-page token count. An agent can compare a short how-to with a longer reference before opening either. The existing 2,000-token limit per compact index still applies; larger catalogs split into linked topic indexes without losing pages.

## Find configuration settings by topic

The [configuration reference](https://www.shoalrun.com/config.md) is now an overview linking to six focused references. The former combined page was about 11,454 tokens; each focused reference is about 1,300–2,600 tokens in the reviewed build. Existing section bookmarks remain available on the overview and link to the new destinations.

The site also has a refreshed logo and favicon. The header mark follows the selected theme, with a text fallback in forced-color mode.

## Keep your place on a phone

Alpha.9 brought section links and page navigation into one mobile **Menu**. Previously, section choices, the page menu, and the outline competed for space above the article. On smaller screens, **Menu** now opens a drawer containing section choices and the current section's pages. You can filter the page list, follow a link, or close the drawer to resume reading.

**On this page** stays with the article as a compact disclosure below its introduction. Choosing a heading closes the disclosure and moves focus to that heading. Pages without an outline omit the control.

## Reach the article sooner

The HTML now places the article before the full site navigation. Readers and tools that process HTML in document order can reach the page content without first passing through the entire menu. Desktop styling still places navigation on the left and the outline on the right.

Keyboard skip links appear when focused without moving the page layout. The mobile drawer keeps focus inside while open; Escape closes it and returns focus to its launcher. If the navigation filter contains text, the first Escape clears the filter and the next closes the drawer. Resizing preserves access to the focused control.

Without JavaScript, Menu remains a link to the navigation below the article, and native disclosures remain usable. Markdown pages and documentation indexes remain available.

See [navigation configuration](https://www.shoalrun.com/author/navigation.md) for section and sidebar settings.
