# Read first and navigate without losing your place

**Published: 2026-10-27.**

**Version: 0.1.0-alpha.9.**

Alpha.9 brings section links and page navigation into one mobile **Menu**. Closing it returns you to the same place in the article. Desktop pages keep their sidebar and outline without adding another row of navigation links.

Upgrade to CLI `0.1.0-alpha.9` and rebuild your site to receive these changes. Existing navigation configuration continues to work.

## Keep your place on a phone

Previously, section choices, the page menu, and the outline competed for space above the article. On smaller screens, **Menu** now opens a drawer containing section choices and the current section's pages. You can filter the page list, follow a link, or close the drawer to resume reading.

**On this page** stays with the article as a compact disclosure below its introduction. Choosing a heading closes the disclosure and moves focus to that heading. Pages without an outline omit the control.

## Reach the article sooner

The HTML now places the article before the full site navigation. Readers and tools that process HTML in document order can reach the page content without first passing through the entire menu. Desktop styling still places navigation on the left and the outline on the right.

Keyboard skip links appear when focused without moving the page layout. The mobile drawer keeps focus inside while open; Escape closes it and returns focus to its launcher. If the navigation filter contains text, the first Escape clears the filter and the next closes the drawer. Resizing preserves access to the focused control.

Without JavaScript, Menu remains a link to the navigation below the article, and native disclosures remain usable. Markdown pages and documentation indexes remain available.

See [navigation configuration](https://www.shoalrun.com/author/navigation.md) for section and sidebar settings.
