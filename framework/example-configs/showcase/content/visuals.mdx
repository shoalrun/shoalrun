## Reconcile the counts

The unresolved count is <Math expression="u = p - d" />, where p is the number of prepared parcels and d is the number with recorded delivery outcomes.

<Math display expression="p = 3,\quad d = 2,\quad u = 1" />

A count alone does not prove delivery; inspect each parcel's recorded outcome.
