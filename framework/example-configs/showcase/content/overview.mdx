## Explore the API

- [Create a parcel enrollment](doc:reference.create-enrollment): compare four program shapes with different required fields and nested objects.
- [List parcel records](doc:reference.cedar.listParcels): use direct query filters and inspect JSON, CSV, and spreadsheet responses.
- [Get a parcel](doc:reference.cedar.getParcel): look up a record on its dedicated server without authentication.
- [Upload a manifest](doc:reference.cedar.uploadManifest): send dispatch data and a checksum as binary files.
- [Parcel delivered event](doc:reference.cedar.parcelDelivered): inspect a webhook with photo and signature proof alternatives.
- [Legacy parcel lookup](doc:reference.cedar.getLegacyParcel): see a deprecated route and its replacement.
