## Validate before displaying

<Walkthrough title="Read a parcel count">
<Step title="Read the field">


Start with fictional local data.

```ts
const receipt = { parcels: 3 };
const count = receipt.parcels;
console.log(count);
```

</Step>
<Step title="Reject invalid counts" highlight="3-5">


Require a nonnegative integer before displaying the count.

```ts
const receipt = { parcels: 3 };
const count = receipt.parcels;
if (!Number.isInteger(count) || count < 0) {
  throw new Error("Invalid parcel count");
}
console.log(count);
```

</Step>
</Walkthrough>
