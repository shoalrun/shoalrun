# Cedar Parcel showcase

Build an editable fictional service handbook with native components, generated API references, and Markdown twins.

```sh
shoalrun build docs.config.yaml site-dist
shoalrun serve site-dist
```

Start at the overview, then follow the handbook pages. `content/features.mdx` maps the examples and explains integrations that need your own services. No provider credentials are required to build. API hosts and operational examples are fictional; replace them before sending requests.
