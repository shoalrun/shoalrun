Scheduled exports are included in Customer A's feature grants. Customer B uses the same Reporting v1 release with manual reporting instructions.

## Configure the delivery

1. Select the account, reporting period, and settlement currency.
2. Choose a daily delivery time after the reporting period closes.
3. Set the delivery destination and save the schedule.

## Verify the first export

Check that the first delivered file uses the expected period and currency. Compare its row count and total with a report generated manually for the same period.
