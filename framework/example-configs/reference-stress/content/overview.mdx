Cedar Parcel is a fictional API for testing reference pages. No server in its OpenAPI file exists, and its examples have not been executed.

Start with [enrollment shapes](doc:guide.enrollment-shapes), then inspect the generated **List parcel records** reference for direct query filters and three successful response formats.

## How it works for agents

The `.md` page includes this guide. Each generated operation also has a Markdown page and a focused OpenAPI contract. Browser-only disclosures do not remove fields from those files.
